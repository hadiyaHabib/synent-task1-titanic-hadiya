#  Titanic Data Cleaning & Preprocessing
##  Problem Statement
The purpose of this project is to clean and preprocess the Titanic dataset to make it ready for data analysis and machine learning tasks.

## Dataset
Dataset used: Titanic Dataset

Dataset Link:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv


##  Objectives
Handle missing values
  Remove duplicate records
  Remove unnecessary columns
 Rename columns for better readability
 Convert data types into proper format

##  Tools & Technologies
 Python
 Pandas
 Jupyter Notebook / Google Colab
 
##  Data Cleaning Steps
Filled missing values in Age column using median
Filled missing values in Embarked column using mode
 Removed Cabin column because of excessive missing values
 Removed duplicate records
 Renamed columns for clarity
 Converted Age column into integer data type


##  Output
A cleaned dataset named `clean_titanic.csv` was generated after preprocessing.

##  Result
The dataset became clean, structured, and ready for exploratory data analysis and machine learning models.
